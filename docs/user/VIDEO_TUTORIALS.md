
## Production Notes

### General Guidelines

**Video Format:**
- Resolution: 1920x1080 (1080p minimum)
- Frame Rate: 30fps
- Format: MP4 (H.264 codec)
- Bitrate: 8-10 Mbps

**Audio:**
- Professional voiceover (clear, neutral accent)
- Background music (subtle, non-distracting)
- Sound effects for UI interactions
- Audio format: AAC, 192 kbps stereo

**Visual Style:**
- Clean, professional interface captures
- Smooth cursor movements (no jerky motion)
- Highlight UI elements with colored outlines/arrows
- Use callout boxes for important tips
- Consistent branding (KryptoVision colors and logo)

**On-Screen Text:**
- Use clear, legible fonts (minimum 24pt)
- High contrast (white text on dark overlay, or vice versa)
- Limit on-screen text duration (3-5 seconds minimum)
- Use bullet points for lists

**Pacing:**
- Speak clearly and not too fast
- Pause between major sections (1-2 seconds)
- Allow time for viewers to process information
- Match voiceover to on-screen actions

### Branding

**Colors:**
- Primary: #1E40AF (Blue)
- Accent: #10B981 (Green)
- Warning: #F59E0B (Yellow)
- Critical: #EF4444 (Red)

**Logo Placement:**
- Lower right corner throughout video
- 50% opacity when not intro/outro
- Full color for intro (0-5s) and outro (last 5s)

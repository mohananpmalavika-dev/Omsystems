# Phase 6 operator training

## HO surveillance operators

- Navigate enterprise summary, branch drill-down, camera grid and saved video-wall layouts.
- Interpret recorder, camera, HDD, internet, recording and retention reason codes.
- Handle P1-P4 alerts: verify evidence, open live video, acknowledge, assign, escalate and document outcome.
- Never suppress a P1 to silence a noisy device; escalate the defective rule/device instead.
- Generate segregated reports and verify artifact expiry before sharing through approved channels.

## Administrators

- Manage least-privilege branch/camera scopes, recipient groups, on-call schedules and health policy.
- Rotate mounted secrets without placing values in tickets, source control or command history.
- Use `/ready`, `/metrics`, Grafana and Prometheus alerts; follow the field runbook before changing capacity.
- Run backup/restore drills and retention maintenance only after evidence preservation checks.

## Practical assessment

Each trainee must complete: one branch-health diagnosis, one retention breach, P1 and P2 test alerts, concurrent acknowledgement exercise, one filtered report, an unauthorized-access verification and a simulated branch reconnect. Record trainee, assessor, environment, attempt date, result and remediation. Production access is granted only after client-approved assessment and role assignment.

Training does not authorize production deployment, database restore, audit modification, secret disclosure or bypassing notification/security controls.

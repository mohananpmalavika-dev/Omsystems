# Render 502 Diagnostic Guide

## Problem
Your Sentinel Grid application on Render is returning 502 Bad Gateway errors, indicating the backend service cannot be reached.

## Root Cause Analysis

Based on your configuration, the most likely causes are:

### 1. **Database Connection Failure (Most Likely)**

Your `/ready` health check requires PostgreSQL connectivity:

```typescript
app.get("/ready", async (_request, reply) => {
  const databasePool = (store as unknown as { pool?: { query(sql: string): Promise<unknown> } }).pool;
  try {
    if (databasePool) await databasePool.query("SELECT 1");
    if (edgePresenceCache) await edgePresenceCache.ping();
    return { status: "ready", database: databasePool ? "connected" : "memory", ... };
  } catch {
    return reply.code(503).send({ status: "not-ready", database: "unavailable" });
  }
});
```

**Check:**
- Is `sentinel-grid-db` database running?
- In Render dashboard → Databases → sentinel-grid-db → Status should be "Available"
- Check database logs for errors

### 2. **Migration Script Silently Failing**

Your Dockerfile CMD runs migrations first:
```dockerfile
CMD ["sh", "-c", "node scripts/run-migrations.mjs && node dist/src/index.js"]
```

The migration script **skips and continues** if DB is unavailable, but the app then fails health checks.

**Fix:** Migration script should exit with error instead of warning:

```javascript
// In run-migrations.mjs around line 238
if (error instanceof Error && /getaddrinfo|ECONNREFUSED|ENOTFOUND|password authentication failed|database .* does not exist/i.test(error.message)) {
  console.error(`Database connection failed: ${error.message}`);
  process.exit(1); // Add this line
}
```

### 3. **Service Startup Timeout**

Render expects services to respond to health checks within ~60 seconds of starting. Your app might be taking too long.

**Check:**
- Review control plane logs for slow startup
- Analytics engine with large AI models could delay startup

### 4. **SSL/TLS Connection Issues**

Your migration script auto-enables SSL for Render:
```javascript
const useSsl = sslSetting === "require" ||
  (sslSetting !== "disable" && hostname.endsWith(".render.com"));
```

But your main app might not have the same logic.

### 5. **Missing Environment Variables**

Critical variables that could cause failures:
- `DATABASE_URL` - Must be set and valid
- `MEDIA_GATEWAY_SHARED_KEY` - Required
- `RECORDING_ENGINE_SHARED_KEY` - Required
- `ANALYTICS_ENGINE_SHARED_KEY` - Required

**These are auto-generated by Render**, but check they exist.

## Quick Fixes

### Fix 1: Make Migration Failures Fatal

Edit `scripts/run-migrations.mjs`:

```javascript
// Replace line 238-241
if (error instanceof Error && /getaddrinfo|ECONNREFUSED|ENOTFOUND|password authentication failed|database .* does not exist/i.test(error.message)) {
  console.error(`FATAL: Database connection failed: ${error.message}`);
  console.error(`Verify DATABASE_URL is set and database is available`);
  process.exit(1);
}
```

### Fix 2: Add Startup Retry Logic

Your health check should retry before failing:

```typescript
// In src/app.ts /ready endpoint
let retries = 3;
while (retries > 0) {
  try {
    if (databasePool) await databasePool.query("SELECT 1");
    return { status: "ready", ... };
  } catch (error) {
    retries--;
    if (retries === 0) throw error;
    await new Promise(resolve => setTimeout(resolve, 2000));
  }
}
```

### Fix 3: Check PostgreSQL SSL Settings

Add to control-plane service in render.yaml:

```yaml
- key: DATABASE_SSL
  value: require
```

### Fix 4: Increase Health Check Timeout

In render.yaml, add for control-plane:

```yaml
healthCheckPath: /ready
healthCheckTimeout: 30  # seconds
```

## Prevention

1. **Add better error logging** in src/index.ts:
```typescript
const config = loadConfig();
console.log('Database URL configured:', !!config.DATABASE_URL);
console.log('Redis URL configured:', !!config.REDIS_URL);
```

2. **Add startup health check** before listening:
```typescript
// Test DB before starting server
if (config.DATABASE_URL) {
  const testPool = createPool(config.DATABASE_URL);
  try {
    await testPool.query('SELECT 1');
    console.log('Database connectivity verified');
  } catch (error) {
    console.error('Cannot connect to database:', error);
    process.exit(1);
  } finally {
    await testPool.end();
  }
}
```

3. **Monitor service metrics** in Render dashboard

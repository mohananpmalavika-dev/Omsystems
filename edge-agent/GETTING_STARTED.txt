STEP 1: Create Desktop Shortcuts (Optional but Recommended)
────────────────────────────────────────────────────────────

  Double-click: CREATE_DESKTOP_SHORTCUTS.bat

  This creates 4 shortcuts on your desktop:
    • Start Edge Agent
    • Check Agent Status
    • View Agent Logs
    • Edge Agent Guide


STEP 2: Start the Edge Agent
────────────────────────────────────────────────────────────

  Choose ONE option:

  🟦 OPTION A: Quick Test (runs in a window)
     Double-click: START_EDGE_AGENT.bat
     
     ✓ Good for: Testing, seeing what's happening
     ✗ Stops when you close the window
     ✗ Doesn't start automatically

  
  🟩 OPTION B: Install as Service (recommended for production)
     Right-click: INSTALL_AS_SERVICE.bat
     Select: "Run as Administrator"
     
     ✓ Good for: Always-on operation
     ✓ Starts automatically on boot
     ✓ Runs in background


STEP 3: Verify It's Working
────────────────────────────────────────────────────────────

  1. Double-click: CHECK_STATUS.bat
     
     You should see:
       [*] Process: RUNNING
  
  2. Wait 2 minutes, then check dashboard:
     
     Open: https://sentinel-grid-control-plane1.onrender.com
     Go to: Operations → Branches → H1
     
     Status should show: 🟢 Online

❓ COMMON QUESTIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


Q: Which option should I choose?
─────────────────────────────────────────────────────────────

  Testing/Demo:        → START_EDGE_AGENT.bat
  Production/Always-on: → INSTALL_AS_SERVICE.bat


Q: How do I know if it's working?
─────────────────────────────────────────────────────────────

  1. Run: CHECK_STATUS.bat
  2. Should see: "Process: RUNNING"
  3. Dashboard shows: 🟢 Online (after 2 min)


Q: Dashboard still shows offline?
─────────────────────────────────────────────────────────────

  Possible causes:

  1. Agent not running
     → Run: CHECK_STATUS.bat
     → If not running, start it

  2. Camera passwords wrong
     → Edit: config\edge-agent-H1.env
     → Fix: CAMERA_USERNAME and CAMERA_PASSWORD
     → Restart agent

  3. Network issues
     → Check computer is on same network as cameras
     → Cameras are on: 192.168.29.x


Q: Where are the logs?
─────────────────────────────────────────────────────────────

  If installed as service:
    C:\Program Files\Sentinel Grid\Edge Agent\logs\edge-agent.log

  If running from folder:
    C:\Omsystems\edge-agent\logs\edge-agent.log


Q: How do I stop it?
─────────────────────────────────────────────────────────────

  If using START_EDGE_AGENT.bat:
    → Press Ctrl+C in the window

  If installed as service:
    → Open Task Scheduler
    → Find "Sentinel Grid Edge Agent"
    → Right-click → End

     (Should show 🟢 Online)

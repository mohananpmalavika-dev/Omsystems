================================================================================
                    EDGE AGENT A1 - GETTING STARTED
================================================================================

You have TWO gateways in your system:
  • H1 Gateway (ID: e89264b4-9168-4b1b-8438-d61f7029668f) - Uses port 8090
  • A1 Gateway (ID: 6fa95d55-76e5-434d-81c5-8868fa9d08dc) - Uses port 8091

This guide is for setting up A1 Gateway.

================================================================================
OPTION 1: QUICK START (Test Mode)
================================================================================

For testing if A1 works:

1. Double-click: START_EDGE_AGENT_A1.bat
2. Watch for messages like "Connected to control plane"
3. Check the dashboard to see if A1 shows online
4. Press Ctrl+C to stop when done testing

This is TEMPORARY - stops when you close the window.

================================================================================
OPTION 2: INSTALL AS SERVICE (Recommended for Production)
================================================================================

To make A1 start automatically with Windows:

STEP 1: Install the Service
   → Double-click: INSTALL_A1_AS_SERVICE.bat
   → Click "Yes" if Windows asks for permission

STEP 2: Start the Service
   → Run: schtasks /run /tn "SentinelEdgeAgent-A1"
   → OR just restart your computer

STEP 3: Check Status
   → Double-click: CHECK_STATUS_A1.bat
   → You should see "Edge Agent A1 process is RUNNING"

================================================================================
IMPORTANT: PORT DIFFERENCES
================================================================================

H1 and A1 use DIFFERENT ports so they don't conflict:

H1 Gateway:
  • Main Port: 8090
  • HLS Port: 8888
  • API Port: 9997
  • Secret Provider: 8093

A1 Gateway:
  • Main Port: 8091 (different!)
  • HLS Port: 8889 (different!)
  • API Port: 9998 (different!)
  • Secret Provider: 8094 (different!)

This allows both H1 and A1 to run on the same computer!

================================================================================
TROUBLESHOOTING: A1 NOT COMING ONLINE
================================================================================

1. CHECK IF A1 IS RUNNING
   → Run: CHECK_STATUS_A1.bat
   → Should say "process is RUNNING"

2. CHECK THE LOGS
   → Open: logs-a1\edge-agent.log
   → Look for errors (red text or "ERROR")

3. COMMON ISSUES:

   ❌ "Connection refused" or "Cannot connect"
      → Check internet connection
      → Check CONTROL_PLANE_URL in config\edge-agent-A1.env

   ❌ "Authentication failed" or "Invalid key"
      → Check EDGE_BRIDGE_SHARED_KEY in config\edge-agent-A1.env
      → Make sure it matches the server

   ❌ "Port already in use" (8091)
      → Another program is using port 8091
      → Stop that program or change the port in config\edge-agent-A1.env

   ❌ Process not running
      → Run: schtasks /run /tn "SentinelEdgeAgent-A1"
      → Check Windows Event Viewer for errors

4. RESTART THE SERVICE
   → Stop it: taskkill /f /im sentinel-edge-agent.exe
   → Start it: schtasks /run /tn "SentinelEdgeAgent-A1"

5. CHECK DASHBOARD
   → Go to: https://sentinel-grid-monitoring1.onrender.com/admin/system
   → Look for A1 in the Gateways list
   → Status should be "online" not "pending"

================================================================================
CHECKING CAMERAS ON A1
================================================================================

Once A1 is online, it will automatically discover cameras on your network.

To see discovered cameras:
1. Open dashboard: https://sentinel-grid-monitoring1.onrender.com
2. Go to Operations → Branches
3. Find your branch (it has both H1 and A1)
4. You should see cameras discovered by both gateways

If cameras are not working:
→ See CAMERA_NOT_WORKING.txt for help

================================================================================
RUNNING BOTH H1 AND A1 TOGETHER
================================================================================

You can run BOTH H1 and A1 at the same time on the same computer!

To run both:
1. Install H1 service: INSTALL_AS_SERVICE.bat
2. Install A1 service: INSTALL_A1_AS_SERVICE.bat
3. Start H1: schtasks /run /tn "SentinelEdgeAgent-H1"
4. Start A1: schtasks /run /tn "SentinelEdgeAgent-A1"

Both will run independently and discover cameras.

================================================================================
UNINSTALLING A1
================================================================================

To remove A1 service:
→ Double-click: UNINSTALL_A1_SERVICE.bat

This will:
  • Stop the A1 process
  • Remove the scheduled task
  • A1 will not start automatically anymore

Your configuration files are kept in case you want to reinstall later.

🎯 PROBLEM

3 cameras are failing because the edge agent is using wrong passwords.


✅ SOLUTION - TWO EASY TOOLS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


TOOL 1: TEST_SINGLE_CAMERA.bat
────────────────────────────────────────────────────────────────

  What it does:
    • Tests one camera at a time
    • Tries common passwords automatically
    • If automatic fails, lets you enter custom password
    • Verifies if password works
    • Option to update config immediately

  How to use:
    1. Double-click: TEST_SINGLE_CAMERA.bat
    2. Enter camera IP: 192.168.29.171
    3. Wait for automatic testing
    4. If failed, choose "Y" to try custom password
    5. Enter your password
    6. If success, choose "Y" to update config now


TOOL 2: FIX_CAMERA_CREDENTIALS.bat
────────────────────────────────────────────────────────────────

  What it does:
    • Interactive 3-way menu
    • Can test passwords automatically
    • Can enter password manually
    • Can open browser for testing
    • Updates config and restarts agent

  How to use:
    1. Double-click: FIX_CAMERA_CREDENTIALS.bat
    2. Choose option:
       
       Option 1: I already know the password
         → Directly enter username/password
       
       Option 2: Test common passwords automatically
         → Enter camera IP
         → Waits for automatic testing
         → If failed, offers custom password entry
         → If found, applies immediately
       
       Option 3: Open camera in web browser
         → Opens browser to camera web interface
         → You test passwords manually
         → Come back and enter working password

📋 STEP-BY-STEP GUIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


METHOD 1: Automatic Testing (Recommended)
──────────────────────────────────────────────────────────────

  STEP 1: Double-click FIX_CAMERA_CREDENTIALS.bat

  STEP 2: Choose option 2 (Test common passwords automatically)

  STEP 3: Enter camera IP: 192.168.29.171

  STEP 4: Wait for automatic testing
    
    The tool will try:
      ✓ admin / (empty)
      ✓ admin / admin
      ✓ admin / 12345
      ✓ admin / 123456
      ✓ admin / 888888

  STEP 5A: If password found
    → Shows: [SUCCESS] Password: xxxxxx
    → Choose Y to use it
    → Config updated automatically
    → Edge agent restarted
    → Done!

  STEP 5B: If no password found
    → Shows: [!] None of the common passwords worked
    → Choose Y to enter custom password
    → Enter your password
    → If correct: Applied automatically
    → If wrong: Try again or use browser method


METHOD 2: Manual Entry (If You Know Password)
──────────────────────────────────────────────────────────────

  STEP 1: Double-click FIX_CAMERA_CREDENTIALS.bat

  STEP 2: Choose option 1 (I already know the password)

  STEP 3: Enter username: admin (or your username)

  STEP 4: Enter password: your_password

  STEP 5: Confirm Y

  STEP 6: Wait for restart

  STEP 7: Verify - shows results after 30 seconds


METHOD 3: Browser Testing (Visual Method)
──────────────────────────────────────────────────────────────

  STEP 1: Double-click FIX_CAMERA_CREDENTIALS.bat

  STEP 2: Choose option 3 (Open camera in web browser)

  STEP 3: Browser opens to http://192.168.29.171

  STEP 4: Try logging in with different passwords:
    - admin / (empty)
    - admin / admin
    - admin / 12345
    - admin / 888888

  STEP 5: Note which password works

  STEP 6: Return to the tool window

  STEP 7: Enter the working username/password

  STEP 8: Confirm and apply

TIP 1: Stop Edge Agent First
  Camera 192.168.29.171 has only 25 attempts left!
  Stop the edge agent before testing to avoid lockout.


TIP 2: Test One Camera
  Once you find the password for one camera, likely all
  cameras use the same password.


TIP 3: Try Automatic First
  Automatic testing is fastest and safest.
  Only use manual methods if automatic fails.


TIP 4: Check Camera Brand
  Different brands have different default passwords:
  
    Hikvision:  (empty) or 12345
    Dahua:      admin or 888888
    CP Plus:    admin or cp123


TIP 5: Use Browser If Stuck
  If nothing works, use browser method to visually see
  the camera login page and try more passwords.

⚠️ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


Problem: "Camera not reachable"
──────────────────────────────────────────────────────────────
  • Check camera is powered on
  • Check computer is on same network (192.168.29.x)
  • Try ping camera: ping 192.168.29.171


Problem: All passwords failed
──────────────────────────────────────────────────────────────
  • Try browser method to see actual error message
  • Camera may be using custom password
  • May need to reset camera to factory defaults
  • Check camera manual for default password


Problem: Password works but still fails after update
──────────────────────────────────────────────────────────────
  • Different cameras may have different passwords
  • Check logs to see which camera is still failing
  • May need per-camera credentials (contact support)


Problem: Edge agent won't restart
──────────────────────────────────────────────────────────────
  • Open Task Scheduler manually
  • Find "Sentinel Grid Edge Agent"
  • Right-click → Run
  OR
  • Close START_EDGE_AGENT.bat window
  • Double-click START_EDGE_AGENT.bat again

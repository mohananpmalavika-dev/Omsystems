Supported QR Code Formats

The scanner automatically detects and parses these common formats:

JSON Format

{"user":"admin",
"pwd":"pass123"}

Key-Value Format

USER:admin;
PWD:pass123

URL Format

http://cam?
user=admin&
pwd=pass123

Comma Format

deviceID,
admin,
pass123,
192.168.1.1
